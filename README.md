# Shiva Rudra | 3D Gaming-Themed Portfolio
so yeah, this is the repo for my personal portfolio website. wanted to build something that looks like roblox or minecraft ui cause standard boring portfolios are mad boring, so I made it all blocky and chunky to showcase my projects and stuff.

🔗 **Live Website:** [https://gangadharpranav.github.io/my_webpage/](https://gangadharpranav.github.io/my_webpage/)

---

what's in here
blocky gaming ui: chunky fonts, thick borders, drop shadows, and floating animated pet blocks.

interactive modals: pop-ups for fake simulations and a working contact form.

responsive: works on phones and pcs.

projects: direct links to live demos and repos.

---

## 🛠️ Built With

- **HTML5** – Semantic document structure.
- **CSS3** – Custom styling, animations, flexbox layouts, and CSS variables.
- **Vanilla JavaScript** – DOM manipulation, interactive modal logic, and form handling.
- **Google Fonts** – *Fredoka One* font for that chunky gaming typography.
