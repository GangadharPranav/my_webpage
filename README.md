# 🎮 Shiva Rudra | 3D Gaming-Themed Portfolio

Welcome to the source code repository of my personal portfolio website! Inspired by classic blocky gaming aesthetics (Roblox & Minecraft UI), this portfolio showcases my projects, skills, and ways to connect with me.

🔗 **Live Website:** [https://gangadharpranav.github.io/my_webpage/](https://gangadharpranav.github.io/my_webpage/)

---

## ✨ Features

- **3D Gaming UI Aesthetic:** Built with chunky fonts, blocky borders, shadow effects, and floating animated pet blocks.
- **Interactive Modals:** Pop-up interfaces providing live simulations and contact forms.
- **Responsive Layout:** Fully optimized for both desktop and mobile screens.
- **Project Showcase:** Direct links to live deployments and GitHub repositories.
